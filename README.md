# Raidin

A responsive web portal for **Raidin**, an Android roadside-assistance service that helps drivers request towing and vehicle support.

[Live website](https://raidin-seven.vercel.app)

## Features

- Android application download flow
- roadside-assistance service presentation
- real-time tracking and secure-payment messaging
- responsive mobile and desktop layouts
- reusable UI components and multilingual content hooks
- contact and support pages

## Technology

Next.js 15, React 19, TypeScript, Tailwind CSS, Radix UI, React Hook Form, Zod, and Lucide.

## Getting started

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Production build

```bash
pnpm build
pnpm start
```

## Project structure

```text
app/          Routes and pages
components/   Reusable interface components
hooks/        Shared React hooks and language support
lib/          Utilities and shared logic
public/       Product imagery and downloadable assets
styles/       Global styling
```

## Product goal

Raidin reduces the friction between a stranded driver and a verified roadside-assistance provider through a simple mobile-first experience.
